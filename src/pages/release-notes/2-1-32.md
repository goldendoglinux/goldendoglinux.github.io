# GoldenDog Linux 2.1.32 GA "Golden Retriever"

GoldenDog Linux is a distribution based on **Debian 13 "trixie"** with a lightly customized version of the **KDE Plasma** desktop. It is designed so that security comes ready out of the box: a system where you can work, browse the web, do your online banking and manage your passwords with peace of mind, without having to be a Linux expert.

## What's New

### Security

- **System hardening for every installation.** The hardened kernel and SSH configuration now ships in the `goldendog-release` package, so existing installations receive it through `apt` as well:
  - **Kernel:** kernel pointers are hidden, `ptrace` is restricted to child processes, core dumps from setuid programs are disabled, and ICMP redirects are ignored.
  - **SSH:** no direct `root` login and no weak algorithms (CBC, SHA-1, MD5). Post-quantum key exchange algorithms are kept.
- **Automatic security updates (optional).** The Security Center can install security patches on its own, in the background, as soon as they are available. They come **disabled**: the choice is yours. Your computer never restarts on its own.
- **Firewall enabled out of the box**, with incoming connections blocked. The SSH and Cockpit services come disabled.
- **GoldenDog Firewall:**
  - The list shows the rules the firewall actually has, and existing rules can be edited and deleted.
  - Deleting a rule now removes it from the firewall. In previous versions it only disappeared from the list, and the port stayed open.
  - Applying changes requires the administrator password.
  - If something fails while applying changes, the firewall automatically returns to its previous state and is never left half-configured.
- **Repositories:** `trixie-proposed-updates` has been removed. GoldenDog only uses packages approved by Debian, plus its own packages, audited by the GoldenDog security team.

### Fixes

- First-boot configuration now finishes **before** the login screen appears, so it can no longer run in parallel with the user's session.
- Flathub is configured even when the first boot happens without an internet connection.
- The installer's **"Check the integrity of the installation media"** option works again.
- Removing SDDM on systems installed with earlier versions no longer leaves the system without a login screen.

### Visual Identity

- GoldenDog's logos, emblems and wallpaper now ship in the `goldendog-theme` package, protected with `dpkg-divert`, so Debian updates no longer replace them with the originals.
- New padlock icon for the security section of GoldenDog Welcome.

### Languages

- GoldenDog Welcome, the Security Center and GoldenDog Firewall are fully translated into 9 languages: Spanish, English, German, French, Dutch, Brazilian Portuguese, Japanese, Simplified Chinese and Hindi.
- The Spanish texts now consistently use a formal register.

### Auditing

- **linaudit 0.3.1** comes preinstalled. A fresh installation scores **95.5%** weighted compliance. It does not reach 100% because some recommendations are meant for servers and do not apply to a desktop computer.

## How to Upgrade

If you already run GoldenDog 2, there is no need to reinstall. Run:

```bash
sudo apt update && sudo apt full-upgrade
```

## Technical Details

- **Base:** Debian 13 "trixie" (stable). GoldenDog starts from Debian's minimal installation (netinst), removes components a desktop does not need, and adds its own packages and configuration, keeping a small footprint.
- **Desktop:** KDE Plasma 6.3, with GDM as the login screen.
- **Kernel:** Debian's Linux 6.12 LTS (6.12.117 at the time of this release).
- **Own repository:** `deb.goldendoglinux.org`, suite `goldenretriever`, signed with the key installed by `goldendog-archive-keyring`.
- **Network installation:** Debian packages are downloaded during installation, so the system is up to date from the first boot. An internet connection is required.

## Known Issues

- GoldenDog's own applications are built with GTK and do not fully match Plasma's (Qt) window style.
- For now, the ISO can only be verified with the published SHA256. GPG signing of the image will arrive in an upcoming release.
- When the `grub-common` package is upgraded, `apt` may ask what to do with `/etc/grub.d/10_linux`, which GoldenDog modifies. Choose to keep the currently installed version (the default option, `N`).
