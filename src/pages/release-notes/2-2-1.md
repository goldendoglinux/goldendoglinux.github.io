# GoldenDog Linux 2.2.1 GA "Golden Retriever"

GoldenDog Linux is a distribution based on **Debian 13 "trixie"** with a lightly customized version of the **KDE Plasma** desktop. It is designed so that security comes ready out of the box: a system where you can work, browse the web, do your online banking and manage your passwords with peace of mind, without having to be a Linux expert.

## What's New

### GoldenDog NVIDIA GPU Setup (testing)

A new application to install and maintain the driver for NVIDIA graphics cards without using the terminal.

- **Detects your card** and only shows the drivers that support it:
  - **Debian driver (version 550):** tested by Debian and updated along with the rest of the system.
  - **NVIDIA driver (newer versions):** from NVIDIA's official repository. It offers better performance on Wayland and in recent games, and it is the only one that supports the newest cards (RTX 50). The branch you choose (for example, 615) stays pinned until you change it, so an update never jumps to another branch on its own.
- **Before changing anything, it test-builds the driver** for every installed kernel. If the build fails, the system is left untouched.
- **Shows the changes before applying them:** which packages will be installed, which will change version and which will be removed.
- **Secure Boot:** it signs the driver and asks you for a one-time password. When you restart, you use that password to enroll the key on the blue MOK Manager screen.
- **A real progress bar** during installation, including the build for each kernel.
- **Diagnostics and repair:** it warns you if any kernel is missing the driver or some of its files, and repairs the installation with a single button.
- You can switch branches, or go back from the NVIDIA driver to the Debian one, at any time.
- It can also be used from the terminal: `sudo goldendog-nvidia-setup status` and `sudo goldendog-nvidia-setup install`.

:::caution Testing
This feature is still being tested. If you run into a problem, you can report it from the link in the application itself or at [github.com/goldendoglinux/support/issues](https://github.com/goldendoglinux/support/issues).
:::

### GoldenDog Welcome

- If your computer has an NVIDIA card, the welcome app shows a new screen with the detected model and offers to install the driver. On computers without NVIDIA, that screen does not appear.
- If the driver is already installed, the screen shows its version and a button to open the setup.

### Installer

- **Installation no longer hangs at "Configure the network"** on networks where the router announces stateless DHCPv6 but no DHCPv6 server answers. This is a bug in the Debian installer (`netcfg` 1.197): once the timeout expires, only one of the two DHCP processes finishes, and the installer waits forever for the other one. It affected both wired and wireless connections. As a workaround, the installer boots without IPv6 (`ipv6.disable=1`) and downloads packages over IPv4. **The installed system keeps IPv6 as usual.**
- `mokutil` comes preinstalled, to enroll Secure Boot keys.

## How to Upgrade

If you already run GoldenDog 2, there is no need to reinstall. Run:

```bash
sudo apt update && sudo apt full-upgrade
```

The upgrade adds GoldenDog NVIDIA GPU Setup as a **recommended** package. If your computer does not have an NVIDIA card, you can remove it without affecting the rest of the system:

```bash
sudo apt remove goldendog-nvidia-setup-gui goldendog-nvidia-setup
```

Once removed, it is not installed again by future updates. While installed, it runs nothing in the background: it has no services and does not start on its own.
