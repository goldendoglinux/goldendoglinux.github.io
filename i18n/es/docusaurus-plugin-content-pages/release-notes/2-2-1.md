# GoldenDog Linux 2.2.1 GA "Golden Retriever"

GoldenDog Linux es una distribución basada en **Debian 13 "trixie"** con una versión ligeramente personalizada del escritorio **KDE Plasma**. Está pensada para que la seguridad venga resuelta de fábrica: un sistema en el que se pueda trabajar, navegar por internet, hacer trámites bancarios y manejar contraseñas con tranquilidad, sin necesidad de ser experto en Linux.

## Novedades

### Configuración de GPU NVIDIA de GoldenDog (en fase de pruebas)

Una aplicación nueva para instalar y mantener el driver de las placas de video NVIDIA sin usar la terminal.

- **Detecta la placa** y muestra solo los drivers compatibles con ella:
  - **Driver de Debian (versión 550):** lo prueba Debian y se actualiza junto con el sistema.
  - **Driver de NVIDIA (versiones más modernas):** proviene del repositorio oficial de NVIDIA. Ofrece mejor rendimiento en Wayland y en juegos recientes, y es el único que soporta las placas más nuevas (RTX 50). La rama elegida (por ejemplo, 615) queda fija hasta que usted la cambie, por lo que una actualización nunca salta a otra rama por su cuenta.
- **Antes de cambiar nada, compila el driver de prueba** para cada kernel instalado. Si no compila, no toca el sistema.
- **Muestra los cambios antes de aplicarlos:** qué paquetes se instalan, cuáles cambian de versión y cuáles se quitan.
- **Secure Boot:** firma el driver y le pide una contraseña de un solo uso. Al reiniciar, esa contraseña se utiliza para registrar la clave en la pantalla azul de MOK Manager.
- **Barra de progreso real** durante la instalación, que incluye la compilación para cada kernel.
- **Diagnóstico y reparación:** avisa si a algún kernel le falta el driver o le faltan archivos, y repara la instalación con un botón.
- Permite cambiar de rama, o volver del driver de NVIDIA al de Debian, en cualquier momento.
- También se puede usar desde la terminal: `sudo goldendog-nvidia-setup status` y `sudo goldendog-nvidia-setup install`.

:::caution En fase de pruebas
Esta función se encuentra en fase de pruebas. Si encuentra un problema, puede reportarlo desde el enlace que figura en la misma aplicación o en [github.com/goldendoglinux/support/issues](https://github.com/goldendoglinux/support/issues).
:::

### GoldenDog Welcome

- Si el equipo tiene una placa NVIDIA, la bienvenida muestra una pantalla nueva con el modelo detectado y ofrece instalar el driver. En equipos sin NVIDIA, esa pantalla no aparece.
- Si el driver ya está instalado, la pantalla muestra la versión y un botón para abrir la configuración.

### Instalador

- **La instalación ya no se cuelga en "Configurar la red"** en redes donde el router anuncia DHCPv6 sin estado (*stateless*) pero ningún servidor DHCPv6 responde. Se trata de un error del instalador de Debian (`netcfg` 1.197): pasado el tiempo de espera, termina solo uno de los dos procesos de DHCP y el instalador se queda esperando indefinidamente al otro. Afectaba tanto a las conexiones por cable como a las inalámbricas. Como solución, el instalador arranca sin IPv6 (`ipv6.disable=1`) y descarga los paquetes por IPv4. **El sistema instalado conserva IPv6 normalmente.**
- `mokutil` viene instalado de fábrica, para registrar claves de Secure Boot.

## Cómo actualizar

Si ya utiliza GoldenDog 2, no necesita reinstalar. Ejecute:

```bash
sudo apt update && sudo apt full-upgrade
```

La actualización agrega la Configuración de GPU NVIDIA de GoldenDog como paquete **recomendado**. Si su equipo no tiene una placa NVIDIA, puede quitarla sin afectar al resto del sistema:

```bash
sudo apt remove goldendog-nvidia-setup-gui goldendog-nvidia-setup
```

Una vez quitada, no se vuelve a instalar en las próximas actualizaciones. Mientras está instalada, no ejecuta nada en segundo plano: no tiene servicios ni se inicia sola.
